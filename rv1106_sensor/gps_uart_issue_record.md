# GPS 串口无数据问题排查记录

## 背景与现象

在板上调试 GPS 模块时，调试串口只输出初始化日志，之后无更多输出。使用 USB 转串口直接连接 GPS 模块可正常看到 NMEA 数据（默认 9600bps）。板上 UART2（PA2/PA3）看到了外部信号，但 STM32 未收到数据。

## 结论概览

问题根因是 FreeRTOS 任务创建失败导致 GPS 串口转发任务未启动。失败原因是任务栈配置过大导致堆不足，GPS Bridge 任务创建失败。

## 详细排查步骤与验证点

### 步骤 1：确认 GPS 模块输出与波特率

结论：模块输出正常，默认 9600bps。
验证方式：

- USB 转串口直接连接模块输出，能够看到类似以下 NMEA 数据：
  - $GNRMC,,V,,,,,,,,,,N,V*37
  - $GPTXT,01,01,01,ANTENNA OPEN*25
- 说明模块正常发射，板端问题可能是 UART 接收或任务未运行。

### 步骤 2：确认 STM32 串口配置

结论：UART2 波特率已配置为 9600bps，格式为 8N1。
验证方式：

- 查看 USART2 初始化配置（MX_USART2_UART_Init）。
- 确保 BaudRate = 9600。

### 步骤 3：定位串口接收逻辑

结论：UART2 接收在独立任务中阻塞读取，并转发到 UART1。
验证方式：

- 查看 FreeRTOS 任务 StartGpsBridgeTask，使用 HAL_UART_Receive(&huart2, &rx_byte, 1, HAL_MAX_DELAY) 接收数据。

### 步骤 4：验证任务是否真正启动

结论：任务未启动，原因是创建失败。
验证方式：

- 在任务创建处增加失败提示日志，发现打印：
  - GPS Bridge Task Create Failed
- 说明任务创建失败而不是 UART 本身收不到数据。

### 步骤 5：检查堆与任务栈

结论：堆不足，任务栈配置过大。
验证方式：

- 输出系统空闲堆与任务栈水位：
  - heap 仅剩 ~800
  - 新增任务创建失败
- 说明堆分配无法满足新任务的栈需求。

### 步骤 6：调整任务栈大小并验证

结论：缩小任务栈后创建成功，GPS 数据开始收到。
验证方式：

- 调整栈大小：
  - defaultTask：2048 → 1024
  - gpsBridgeTask：512 → 256
  - ledBlinkTask：256 → 128
- 重新运行后不再出现创建失败提示。
- GPS Bridge 任务开始运行，UART2 数据能够转发到 UART1。

## 最终修复内容

1. UART2 波特率设置为 9600。
2. 增加 UART2→UART1 转发任务。
3. 缩小任务栈，确保堆空间充足，任务可创建。

## 诊断打印与栈水位说明

当启用 `INCLUDE_uxTaskGetStackHighWaterMark` 时，可使用栈水位 API 观察任务运行时的最小剩余栈。该值是“历史最低剩余栈”（以字为单位），值越小越接近栈溢出。

### 常用诊断打印示例

```
DBG loop=6 gps_rx=0 led=4 heap=800 stack_def=1706 stack_gps=1706 stack_led=184
```

### 每个字段含义

- loop：主任务循环次数，用于确认主任务在持续运行。
- gps_rx：串口2收到并转发的字节数，用于确认 UART2 接收是否在增长。
- led：LED 线程闪烁次数，用于确认 LED 任务是否在运行。
- heap：FreeRTOS 当前剩余堆空间（字节），用于判断是否存在堆不足导致任务创建失败。
- stack_def：defaultTask 的栈高水位（字为单位），用于评估主任务栈是否充足。
- stack_gps：gpsBridgeTask 的栈高水位（字为单位），用于评估串口转发任务栈是否充足。
- stack_led：ledBlinkTask 的栈高水位（字为单位），用于评估 LED 任务栈是否充足。

### 解读要点

- heap 持续过低或任务创建失败，说明需要减小任务栈或增大堆。
- stack_* 值过小（例如接近 0），说明该任务栈可能不够，需要增大。
- gps_rx 长期为 0，说明 UART2 没收到数据，需检查接线或串口配置。

## 可复用的验证清单

1. USB 转串口确认模块输出正常。
2. 确认 UART2 引脚接线与电平匹配。
3. 确认 UART2 配置波特率、格式一致。
4. 确认 FreeRTOS 任务创建成功。
5. 检查堆空间和任务栈水位是否足够。
