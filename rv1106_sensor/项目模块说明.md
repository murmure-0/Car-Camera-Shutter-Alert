# STM32 传感器系统模块说明

## 项目概述

本项目是一个基于 STM32 的多传感器数据采集与控制系统，集成了 MPU6050、AHT30、INA226、GPS 等传感器，支持步进电机控制、按键交互和 RV1106 电源管理。

## 文件功能说明

### 1. 主程序文件

#### `main.c`
**功能**：系统初始化和主循环

**主要职责**：
- MCU 复位和时钟配置
- GPIO、ADC、UART 初始化
- 传感器上电和初始化
- FreeRTOS 初始化
- 启动调度器

**关键函数**：
- `main()` - 系统入口点
- `SystemClock_Config()` - 系统时钟配置
- `MX_FREERTOS_Init()` - FreeRTOS 初始化

**初始化流程**：
1. 电源初始化（传感器电源、RV1106电源）
2. I2C 总线初始化（MPU6050、AHT30、INA226）
3. 传感器初始化（MPU6050、AHT30、INA226）
4. 步进电机初始化
5. GPS 模块初始化
6. FreeRTOS 任务创建

---

### 2. 任务队列模块

#### `task_queue.h`
**功能**：消息队列头文件，定义消息类型和接口

**主要定义**：
- `TaskMsgType_t` - 消息类型枚举
  - `TASK_MSG_KEY_PRESS` - 按键消息
  - `TASK_MSG_SENSOR_UPDATE` - 传感器更新
  - `TASK_MSG_GPS_UPDATE` - GPS 更新
  
- `KeyMsg_t` - 按键消息结构
  - `key_id` - 按键ID (0=PA0, 1-3=PC1按键)
  - `press_type` - 按键类型 (0=短按, 1=长按)
  
- `SensorMsg_t` - 传感器消息结构
- `GPSMsg_t` - GPS 消息结构
- `TaskMsg_t` - 通用消息结构（使用 union）

**导出函数**：
- `TaskQueue_Init()` - 初始化消息队列
- `TaskQueue_SendKeyMsg()` - 发送按键消息
- `TaskQueue_SendSensorMsg()` - 发送传感器消息
- `TaskQueue_SendGPSMsg()` - 发送GPS消息
- `TaskQueue_ReceiveMsg()` - 接收消息

#### `task_queue.c`
**功能**：消息队列实现

**主要实现**：
- 创建 FreeRTOS 消息队列（16个消息深度）
- 实现消息发送和接收函数
- 消息数据打包和解包

**队列配置**：
- 队列长度：16
- 消息大小：`sizeof(TaskMsg_t)`

---

### 3. 按键处理模块

#### `key_handler.h`
**功能**：按键处理头文件

**主要定义**：
- `KEY_ID_PA0` - PA0独立按键
- `KEY_ID_PC1_KEY1` - PC1 ADC按键1
- `KEY_ID_PC1_KEY2` - PC1 ADC按键2
- `KEY_ID_PC1_KEY3` - PC1 ADC按键3
- `KEY_PRESS_SHORT` - 短按
- `KEY_PRESS_LONG` - 长按

**导出函数**：
- `KeyHandler_Init()` - 按键初始化
- `KeyHandler_ScanTask()` - 按键扫描任务
- `KeyHandler_GetKeyState()` - 获取按键状态

#### `key_handler.c`
**功能**：按键检测和消息发送

**主要职责**：
- 轮询扫描所有按键状态
- 检测按键按下和松开事件
- 检测长按（持续2秒以上）
- 通过消息队列发送按键事件

**按键检测逻辑**：
1. **PC1 ADC按键**：
   - 读取 ADC 值判断按键类型
   - 记录按下时间
   - 2秒内松开 → 短按
   - 持续2秒 → 长按

2. **PA0独立按键**：
   - 读取 GPIO 状态
   - 同样的长按检测逻辑

**时间配置**：
- 扫描周期：100ms
- 长按阈值：2000ms (2秒)

---

### 4. 业务处理模块

#### `business_handler.h`
**功能**：业务处理头文件

**导出函数**：
- `BusinessHandler_Init()` - 业务处理初始化
- `BusinessHandler_Task()` - 业务处理任务
- `BusinessHandler_ProcessKeyEvent()` - 处理按键事件
- `BusinessHandler_ProcessSensorUpdate()` - 处理传感器更新
- `BusinessHandler_ProcessGPSUpdate()` - 处理GPS更新

#### `business_handler.c`
**功能**：业务逻辑处理

**主要职责**：
- 接收消息队列中的消息
- 根据消息类型分发到对应的处理函数
- 实现具体的业务逻辑

**按键处理逻辑**：

1. **PA0 长按** - 开关机控制
   ```c
   if (rv1106_power_on == 0) {
       // 开机流程
       Stepper_SetAngle(60.0f);     // 电机转到60度
       BSP_Power_SetRV1106Power(1); // 打开RV1106电源
       rv1106_power_on = 1;
   } else {
       // 关机流程
       Stepper_SetAngle(0.0f);      // 电机转到0度
       BSP_Power_SetRV1106Power(0); // 关闭RV1106电源
       rv1106_power_on = 0;
   }
   ```

2. **PC1 按键** - 状态输出
   - 短按：输出按键名称
   - 长按：输出按键名称 + "_LONG"

**扩展点**：
- 所有处理函数都预留了 TODO 注释
- 可以轻松添加新的业务逻辑

### 5. 传感器采集模块

#### `freertos.c` - `StartDefaultTask`
**功能**：传感器数据采集任务

**主要职责**：
- 定期采集所有传感器数据
- 计算姿态角（俯仰、横滚、航向）
- 发送传感器数据

**采集数据**：
1. **MPU6050**：
   - 加速度（X/Y/Z）
   - 陀螺仪（X/Y/Z）
   - 温度
   - 计算：俯仰角、横滚角、航向角

2. **AHT30**：
   - 温度
   - 湿度

3. **INA226**：
   - 总线电压
   - 分流电压
   - 电流
   - 功率

4. **ADC**：
   - 电池电压
   - 霍尔传感器1
   - 霍尔传感器2

5. **步进电机**：
   - 当前角度

**发送频率**：每 200ms 发送一次（两次间隔100ms）

---

#### `freertos.c` - `StartGpsBridgeTask`
**功能**：GPS 数据桥接任务

**主要职责**：
- 从 UART2 接收 GPS NMEA 数据
- 解析 GNGGA 帧
- 提取经纬度和卫星数量
- 更新全局变量

**数据流**：
```
GPS模块 → UART2 → NMEA解析 → g_gps_lat/g_gps_lon/g_gps_sat
```

---

#### `freertos.c` - `StartLedBlinkTask`
**功能**：LED 状态指示任务

**主要职责**：
- 每 500ms 翻转 LED 状态
- 提供系统运行指示

**LED 控制**：
- 翻转 PB 口的 LED_OUT1-4

#### `ina226.h/c`

## 任务优先级

| 任务名称 | 优先级 | 说明 |
|---------|--------|------|
| gpsBridgeTask | AboveNormal | GPS数据接收需要及时处理 |
| defaultTask | Normal | 传感器数据采集 |
| keyScanTask | Normal | 按键扫描 |
| businessTask | Normal | 业务处理 |
| ledBlinkTask | Low | LED指示 |

## 消息类型说明

### 按键消息
```c
{
    type: TASK_MSG_KEY_PRESS,
    key_id: 0-3,           // 0=PA0, 1-3=PC1按键
    press_type: 0-1        // 0=短按, 1=长按
}
```

### 传感器消息
```c
{
    type: TASK_MSG_SENSOR_UPDATE,
    temperature: float,     // 温度
    humidity: float,        // 湿度
    battery_voltage: float, // 电池电压
    motor_angle: float      // 电机角度
}
```

### GPS消息
```c
{
    type: TASK_MSG_GPS_UPDATE,
    latitude: float,        // 纬度
    longitude: float,       // 经度
    satellites: uint8_t     // 卫星数量
}
```

## 扩展开发指南

### 添加新按键功能
1. 在 `key_handler.h` 中定义按键ID
2. 在 `business_handler.c` 的 `BusinessHandler_ProcessKeyEvent()` 中添加处理逻辑

### 添加新传感器
1. 创建传感器驱动模块（参考 mpu6050.c）
2. 在 `defaultTask` 中添加数据采集
3. 如需消息通知，在 `task_queue.h` 中添加消息类型

### 添加新业务逻辑
1. 在 `business_handler.h` 中声明处理函数
2. 在 `business_handler.c` 中实现处理逻辑
3. 在 `BusinessHandler_Task()` 的 switch 中添加分支

## 系统启动流程

```
1. HAL_Init()                    // 复位外设
2. SystemClock_Config()          // 配置系统时钟
3. MX_GPIO_Init()                // 初始化GPIO
4. MX_ADC1_Init()                // 初始化ADC
5. MX_USARTx_UART_Init()         // 初始化串口
6. BSP_Power_Init()              // 电源初始化
7. BSP_Power_SetSensorPower(1)   // 打开传感器电源
8. BSP_Power_SetRV1106Power(1)   // 打开RV1106电源
9. SoftI2C_Init()                // 初始化I2C
10. MPU6050_Init()               // 初始化MPU6050
11. AHT30_Init()                 // 初始化AHT30
12. INA226_Init()                // 初始化INA226
13. Stepper_Init()               // 初始化步进电机
14. GPS_Init()                   // 初始化GPS
15. TaskQueue_Init()             // 初始化消息队列
16. MX_FREERTOS_Init()           // 创建FreeRTOS任务
17. osKernelStart()              // 启动调度器
```

---

## 注意事项

1. **消息队列大小**：16个消息，如果消息产生速度过快可能丢失
2. **长按时间**：2秒，可在 `key_handler.c` 中修改
3. **传感器采集频率**：每 200ms 采集一次
4. **栈大小**：根据实际使用情况调整
5. **电源管理**：RV1106电源由 PA0 长按控制
