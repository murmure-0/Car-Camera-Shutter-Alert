# STM32 - RV1106 通信协议文档

本文档描述了 STM32 传感器控制板与 RV1106 主控板之间的通信协议。

## 1. 物理层
*   **接口**: UART (TTL电平)
*   **波特率**: 115200 (默认) / 9600
*   **数据位**: 8
*   **停止位**: 1
*   **校验位**: 无
*   **流控**: 无

## 2. 协议格式
通信采用 **JSON 文本行** 格式。每条消息占一行，以换行符 `\n` (0x0A) 结尾。

### 2.1 STM32 -> RV1106 (传感器数据上报)
STM32 周期性（例如 2Hz）发送包含所有传感器状态的 JSON 对象。

**示例数据包:**
```json
{
  "temp": 25.50,
  "humi": 60.20,
  "mpu": {
    "ax": 0.02,
    "ay": 0.05,
    "az": 1.01,
    "gx": 0.01,
    "gy": -0.02,
    "gz": 0.00,
    "t": 26.5,
    "ang": {
      "roll": 1.50,
      "pitch": -0.80,
      "yaw": 12.30
    }
  },
  "pwr": {
    "v": 5.05,
    "vs": 2.50,
    "i": 0.1500,
    "p": 0.7575
  },
  "adc": {
    "bat": 4.15,
    "h1": 2048,
    "h2": 2050
  },
  "gps": {
    "lat": 0.000000,
    "lon": 0.000000,
    "sat": 0
  },
  "motor": {
    "ang": 15.50
  }
}
```

**字段说明:**

| 根键 | 子键 | 类型 | 单位 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `temp` | - | float | °C | AHT30 环境温度 |
| `humi` | - | float | %RH | AHT30 环境湿度 |
| `mpu` | `ax`, `ay`, `az` | float | g | 三轴加速度 |
| `mpu` | `gx`, `gy`, `gz` | float | deg/s | 三轴角速度 |
| `mpu` | `t` | float | °C | MPU6050 芯片温度 |
| `mpu` | `ang.roll` | float | deg | 横滚角 |
| `mpu` | `ang.pitch` | float | deg | 俯仰角 |
| `mpu` | `ang.yaw` | float | deg | 偏航角 |
| `pwr` | `v` | float | V | 总线电压 (INA226) |
| `pwr` | `vs` | float | mV | 分流电阻电压 (INA226) |
| `pwr` | `i` | float | A | 电流 (INA226) |
| `pwr` | `p` | float | W | 功率 (INA226) |
| `adc` | `bat` | float | V | 电池电压 |
| `adc` | `h1` | int | - | 霍尔传感器1原始ADC值 (0-4095) |
| `adc` | `h2` | int | - | 霍尔传感器2原始ADC值 (0-4095) |
| `gps` | `lat` | float | deg | 纬度 |
| `gps` | `lon` | float | deg | 经度 |
| `gps` | `sat` | int | - | 卫星数量 |
| `motor` | `ang` | float | deg | 步进电机当前角度 (累积值) |

### 2.2 RV1106 -> STM32 (控制指令 - 预留)
目前协议主要为单向上传。如果需要控制（例如控制电机），建议采用以下 JSON 格式：

**电机控制示例:**
```json
{"cmd":"motor_move", "steps": 100, "speed": 2}
```

**复位指令:**
```json
{"cmd":"system_reset"}
```

## 3. 注意事项
1.  **浮点精度**: JSON 中的浮点数保留 2-6 位小数，具体取决于字段重要性。
2.  **解析**: 接收端应使用标准 JSON 解析器（如 Python `json` 库或 C++ `cJSON`）。
3.  **角度**: `motor.ang` 是基于步数的累积计算值。系统上电时默认为 0 度。如果电机丢步，该值可能会有偏差。
